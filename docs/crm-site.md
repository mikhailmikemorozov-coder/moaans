# Сайт ↔ CRM: заявки, статус заказа, капча

Всё включается переменными окружения в Vercel (Project → Settings → Environment Variables, затем Redeploy).
Пока переменные пустые, сайт работает ровно как раньше.

| Переменная | Что это | По умолчанию |
|---|---|---|
| `VITE_BC_SITE_KEY` | Публичный ключ сайта из CRM. Включает отправку заявок в CRM и кнопку «Узнать статус заказа». | пусто — выключено |
| `VITE_BC_API` | Адрес CRM. | `https://crm.bi-color.ru` |
| `VITE_SMARTCAPTCHA_KEY` | **Клиентский** ключ Yandex SmartCaptcha. Включает капчу в обеих формах. | пусто — без капчи |

## Заявка с сайта
Форма «Оставьте заявку» по-прежнему отправляет письмо через Google Apps Script (не удалять, пока путь в CRM не проверен)
и, если задан `VITE_BC_SITE_KEY`, одновременно шлёт `POST {API}/api/bc/public/{key}/lead`
(`name, phone, service, comment, website, captcha`). «Заявка принята» показывается, если сработал хотя бы один путь.
`website` — скрытое поле-ловушка для ботов (люди его не видят).

## Статус заказа
Кнопка «Узнать статус заказа» под главными кнопками на первом экране и в мобильном меню (только при `VITE_BC_SITE_KEY`).
Клиент вводит номер заказа и последние 4 цифры телефона → `POST {API}/api/bc/public/{key}/status`.
Показываем статус, срок (дд.мм), «К оплате: N ₽» или «Оплачено»; для готовых заказов — адрес и часы работы.
Ошибки: «Заказ не найден…», «Слишком много попыток, попробуйте через 10 минут», сетевая ошибка.

## Как включить капчу
1. Yandex Cloud → SmartCaptcha → «Создать капчу», домены: `bi-color.ru`, `www.bi-color.ru`.
2. **Ключ клиента** → `VITE_SMARTCAPTCHA_KEY` в Vercel, Redeploy.
3. **Ключ сервера** → в настройки CRM-сервера (на сайт его не класть).
Скрипт капчи грузится только когда форма с капчей появляется на экране. Без ключа сайт отправляет `captcha: ""`.
